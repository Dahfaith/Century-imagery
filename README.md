# Century Imagery LLC — Digital Motion Picture Studio

Official web platform for **Century Imagery LLC**, a digital motion picture and cinematography studio directed by Founder & Executive Creative Director **Akin Idowu**.

Operating from studio headquarters in Ibadan with active deployments in Lagos and worldwide transit, Century Imagery crafts motion pictures, commercial brand films, state protocol archives, luxury event cinema, and high-contrast portraiture.

---

## Brand Architecture & Disciplines

- **01 Film & Cinema Production** — Narrative features, high-contrast anamorphic cinema, and long-form visual drama.
- **02 Commercial & Brand Production** — High-impact commercial visual identities and brand campaign films.
- **03 Luxury Event Cinema** — Heirloom wedding films and high-society celebratory motion picture archives.
- **04 The Century Post Lab** — Film-grade color timing, sound design synchronization, and master finishing.
- **05 Aerial & Specialized Optics** — Licensed high-altitude drone cinematography and technical gimbal motion.
- **06 Photography Division** — Fine-art editorial portraiture and high-contrast stills.
- **07 Production Support** — Cinema camera packages, prime glass sets, wireless monitoring, and specialized rigging.

---

## Technology Stack

- **Framework**: Next.js 15 (App Router)
- **Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Motion & Interactions**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Figtree (Google Fonts via Next.js Font Optimization)

## Getting Started

### Prerequisites

- Node.js 18.17+ or later
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Dahfaith/Century-imagery.git

# Enter repository directory
cd Century-imagery

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the platform.

### Production Build

```bash
npm run build
npm run start
```
